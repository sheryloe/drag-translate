# 드래그 번역 (drag-translate)

웹 페이지와 **PDF**에서 글자를 마우스로 드래그하면 그 자리에서 번역해 주는 **크롬 확장 프로그램**입니다.

- **구글 번역**: 선택한 글 바로 아래에 번역 창이 뜹니다. 키나 가입이 필요 없습니다.
- **파파고**: 번역 창의 「파파고에서 번역 보기」를 누르면 파파고 사이트가 새 탭으로 열리고, 고른 글이 미리 채워져 있습니다.
- **로컬(내 PC) 번역**: 내 PC 안에서 도는 작은 언어 모델(Ollama, LM Studio)로 번역합니다. **글이 PC 밖으로 나가지 않아** 보안 문서에 씁니다.
- **화면 영역 번역**: 스캔한 PDF·화면 캡처처럼 그림으로 된 글자를 영역을 골라 내 PC 모델로 읽고 번역합니다.
- **PDF**: PDF를 열면 확장에 들어 있는 **PDF 번역 뷰어**(Mozilla PDF.js)로 열립니다. 쪽 안의 글자를 드래그하면 똑같이 번역됩니다.

![PDF에서 문장을 드래그하면 바로 아래에 구글 번역이 뜬다](docs/screenshot-pdf.jpg)

## 설치 방법

크롬 웹 스토어에 올리지 않은 확장이라 **「압축해제된 확장 프로그램」으로 직접 설치**합니다. 5분이면 됩니다.
크롬 120 이상에서 동작하고, 같은 바탕인 엣지와 웨일에서도 됩니다.
처음 쓰는 직원용 한 장짜리 안내와 회사 일괄 설치 개요는 [docs/설치안내.md](docs/설치안내.md)에 있습니다(설치본 zip에도 들어 있습니다).

### 1. 파일 받기

셋 중 하나를 고르세요.

- **배포 묶음으로 받기**: 받은 `drag-translate-1.1.1.zip`의 압축을 풉니다. 개발자가 `npm run pack`으로 만든 묶음입니다(아래 [개발](#개발)).
- **ZIP으로 받기**: 이 페이지 위쪽의 초록색 **`Code`** 단추 → **`Download ZIP`** → 받은 파일의 압축을 풉니다.
  예: `D:\tools\drag-translate-main` (이 폴더 안에 `manifest.json`이 바로 보여야 합니다)
- **git으로 받기**
  ```bash
  git clone https://github.com/sheryloe/drag-translate.git
  ```

> 설치한 뒤에 이 폴더를 지우거나 옮기면 확장이 사라집니다. 지워지지 않을 곳에 두세요.

### 2. 크롬에 올리기

1. 주소창에 **`chrome://extensions`** 를 입력해 확장 프로그램 관리 화면을 엽니다.
2. 오른쪽 위 **「개발자 모드」** 를 켭니다.
3. 왼쪽 위 **「압축해제된 확장 프로그램을 로드합니다」** 를 누릅니다.
4. 1단계에서 받은 폴더(`manifest.json`이 들어 있는 폴더)를 고르고 **「폴더 선택」** 을 누릅니다.
5. 목록에 **「드래그 번역 (Drag Translate)」** 이 나타나면 설치가 끝난 것입니다. 설정 화면이 한 번 자동으로 열립니다.
6. 주소창 오른쪽의 퍼즐 모양 아이콘 → 「드래그 번역」 옆 **핀(📌)** 을 누르면 도구 막대에 아이콘이 고정됩니다.

### 3. (선택) 내 컴퓨터의 PDF도 쓰려면

`file:///C:/…/문서.pdf`처럼 **내 컴퓨터의 PDF 파일**을 번역 뷰어로 열려면 권한을 하나 더 켜야 합니다.

1. `chrome://extensions` → 「드래그 번역」의 **「세부정보」**
2. **「파일 URL에 대한 액세스 허용」** 을 켭니다.

이 권한을 켜지 않아도, 번역 뷰어의 **「파일 열기」**로 같은 파일을 고르거나 창에 끌어 놓으면 볼 수 있습니다.

### 4. (선택) 보안 문서용 로컬 번역

회사 문서처럼 밖으로 보내면 안 되는 글을 번역하려면 [로컬 번역 쓰기](#로컬-번역-쓰기)를 따라 Ollama와 모델을 설치합니다.

### 엣지·웨일에서 설치

- 엣지: `edge://extensions` → 왼쪽 아래 「개발자 모드」 → 「압축 풀린 항목 로드」 → 폴더 선택
- 웨일: `whale://extensions` → 「개발자 모드」 → 「압축해제된 확장앱을 로드합니다」 → 폴더 선택

### 업데이트

새 버전을 받아 같은 폴더에 덮어씁니다(git이면 `git pull`). 그다음 `chrome://extensions`에서 「드래그 번역」의 **새로고침(⟳)** 아이콘을 누르세요.
이미 열려 있던 탭은 새로 고쳐야 새 버전이 붙습니다.

## 설치 뒤 5분 확인 순서

설치한 크롬에서 한 번 차례로 해 보는 순서입니다. 단계마다 **기대 결과**가 안 나오면 「막히면」 칸을 봅니다.
배경 작업 기록은 `chrome://extensions` → 「드래그 번역」 카드의 **「서비스 워커」** 링크, 번역 창·뷰어 기록은 그 탭에서 **F12 → Console** 에서 봅니다.

| 순서 | 할 일 | 기대 결과 | 막히면 |
|---|---|---|---|
| 1. 설치(1분) | `chrome://extensions` → 개발자 모드 켜기 → 「압축해제된 확장 프로그램을 로드합니다」 → `manifest.json`이 든 폴더 선택 | 카드에 「드래그 번역 (Drag Translate)」 1.1.1, 오류 표시 없음. 설정 화면이 한 번 열림 | 카드의 빨간 「오류」 단추를 눌러 내용 확인. 폴더를 한 단계 잘못 골랐으면(`manifest.json`이 바로 안 보이면) 다시 고름 |
| 2. 내 PC 엔진 연결(1분) | Ollama가 켜져 있는지 확인 → 팝업에서 엔진 「내 PC」 → 설정 「모델 이름」에 받아 둔 모델(예: `ollama list`에 나오는 이름) → 「연결 시험」 | 「연결됐습니다. (n초) 시험 번역: 안녕하세요. 이것은 연결 시험입니다.」 비슷한 글. 처음은 수십 초 걸릴 수 있음 | 「꺼져 있습니다」→ Ollama 켜기. 「막았습니다(403)」→ [문제 해결](#문제-해결)의 OLLAMA_ORIGINS. 「모델 …이(가) 없습니다」→ 결과 끝의 「받아 둔 모델」 가운데 하나를 「모델 이름」에 넣기 |
| 3. 웹 페이지 드래그(30초) | 아무 영어 기사(예: 위키백과 영어판)를 **새로 열고** 한 문장을 드래그 | 선택 바로 아래 번역 창. 「구글」이면 1초 안팎, 「내 PC」면 「내 PC에서 번역 중… n초」 뒤 번역. 「복사」→ 메모장에 붙여 넣으면 번역문 | 설치 전부터 열려 있던 탭이면 새로 고침. 팝업 스위치가 켜져 있는지. 입력칸 안 선택은 무시함 |
| 4. PDF(1분) | 주소가 `.pdf`로 끝나는 PDF 링크를 엶(예: 회사 공개 자료, 논문 PDF) → 쪽 안 문장 드래그 | 크롬 기본 뷰어가 아니라 위에 「파일 열기 · 영역 번역 · 원래 뷰어로 보기」 막대가 있는 **PDF 번역 뷰어**로 열리고, 드래그하면 줄 끝이 이어진 문장으로 번역 | 「PDF를 불러오지 못했습니다」→ 로그인 필요한 문서. 「원래 뷰어로 보기」 뒤 우클릭 「내 PC로 번역」. 내 컴퓨터 파일은 팝업 「PDF 파일 열기」로 고름 |
| 5. 화면 영역 OCR(1분) | 그림 속 글자가 있는 페이지에서 팝업 「화면 영역 골라 번역(내 PC)」 → 글자 부분을 끌어 고름 | 화면이 어두워졌다가 「그림 속 글자를 내 PC에서 읽는 중…」 → 읽은 글이 번역 창에 들어가 번역 | 「그림을 읽을 수 있는 모델을 골라 주세요」→ 시각 모델(`qwen3-vl:2b-instruct` 등)을 받아 설정 「그림 읽기 모델」에 넣기(연결 시험 결과 마지막 줄에 가능 여부가 나옴). 「이 화면에서는 영역 번역을 쓸 수 없습니다」→ 크롬 내부 화면·웹 스토어 |
| 6. 긴 글(1분) | 「내 PC」 엔진으로 문단 서너 개(1,500자쯤)를 한꺼번에 드래그 | 「내 PC에서 번역 중… 1/3 조각 (33%) n초」처럼 조각 수가 올라가며 끝난 앞부분이 먼저 보이고, 끝나면 문단 모양 그대로 번역. 30,000자를 넘기면 「앞 …자만 번역합니다. 남은 …자는 번역하지 않았습니다」 | 「…초 안에 답하지 않았습니다」→ 설정 「기다리는 시간」 늘리기. 「배경 작업이 답을 주기 전에 멈췄습니다」→ 다시 시도, 서비스 워커 기록 확인 |

다 되면 결과(되었는지, 걸린 시간, 막힌 단계의 문구 그대로)를 적어 개발자에게 알려 주세요.

## 사용 방법

### 웹 페이지

1. 번역하고 싶은 글을 마우스로 **드래그**합니다. 두 번 눌러 낱말 하나를 골라도 됩니다.
2. 선택 바로 아래에 **번역 창**이 뜹니다.

| 번역 창에서 | 하는 일 |
|---|---|
| **구글** / **파파고 ↗** / **내 PC** | 번역 엔진을 바꿉니다. 고른 엔진은 다음에도 기본값으로 남습니다. |
| 언어 고르기(한국어 ▾) | 번역할 언어를 바꿉니다(13개 언어, 아래 [설정](#설정) 참고). 원문 언어는 자동으로 알아냅니다. |
| **복사** | 아래 「복사: …」에서 고른 모양으로 클립보드에 넣습니다. |
| 복사: 번역문만 ▾ | 복사 방식(번역문만 / 원문과 번역 나란히 / 표)을 고릅니다. 고른 방식을 기억합니다. |
| **✕** 또는 **Esc** | 창을 닫습니다. 창 밖을 눌러도 닫힙니다. |
| 구글 번역에서 열기 ↗ | 같은 글을 구글 번역 사이트에서 엽니다(「내 PC」일 때는 보이지 않습니다). |

**파파고**를 고르면 번역 창에 고른 글과 **「파파고에서 번역 보기 ↗」** 단추가 보입니다. 누르면 파파고가 새 탭에서 번역합니다.
파파고는 결과를 그 자리로 받아 올 무료 통로가 없어서 새 탭으로 엽니다. 드래그할 때마다 탭이 열리지 않도록 단추를 한 번 누르게 했습니다.

**내 PC**를 고르면 내 PC의 언어 모델이 번역합니다. 구글보다 느려서 번역 창에 「내 PC에서 번역 중… 2/5 조각 3초」처럼 진행 상황과 끝난 앞부분이 먼저 보입니다.
같은 글을 다시 고르면 기억해 둔 결과를 바로 보입니다(브라우저를 닫으면 지워집니다).

### PDF

- **PDF 주소를 열면** 크롬 기본 뷰어 대신 **PDF 번역 뷰어**로 열립니다. 쪽 안의 글자를 드래그하면 웹 페이지와 똑같이 번역됩니다.
- PDF에서 고른 글은 줄 끝마다 끊겨 있기 쉽습니다. 확장이 **끊긴 줄을 합친 뒤**(줄 끝 하이픈, 문장 중간 줄바꿈) 번역합니다. 목록과 문단 나눔은 남깁니다.
- 위쪽 막대에는 「파일 열기」, 쪽 이동(◀ 쪽 번호 ▶), 확대·축소(− 폭 맞춤 +), **「영역 번역」**, 「원래 뷰어로 보기」, 「설정」이 있습니다.
- 스캔한 쪽처럼 글자를 고를 수 없는 곳은 **「영역 번역」** 을 누르고 글자가 있는 곳을 끌어 고릅니다([화면 영역 번역](#화면-영역-번역)).
- PDF **링크를 우클릭**하면 「이 PDF를 번역 뷰어로 열기」가 나옵니다.
- 이미 크롬 기본 뷰어로 열린 PDF는 도구 막대의 확장 아이콘 → 「이 PDF를 번역 뷰어로 열기」로 옮깁니다.
- 내 컴퓨터의 PDF는 확장 아이콘 → 「PDF 파일 열기」를 누르거나, 번역 뷰어 창에 파일을 **끌어 놓습니다**.
- 로그인이 필요한 문서처럼 크롬 기본 뷰어를 써야 할 때는 「원래 뷰어로 보기」를 누릅니다. 그 문서는 이번 브라우저 실행 동안 번역 뷰어로 자동 전환되지 않습니다.
  크롬 기본 뷰어 안에서도 글자를 고른 뒤 **우클릭 → 「구글로 번역」·「내 PC로 번역」** 을 누르면 작은 결과 창으로 번역을 볼 수 있습니다.

### 우클릭 메뉴

| 메뉴 | 하는 일 |
|---|---|
| **구글로 번역: “…”** | 선택 옆(또는 작은 결과 창)에 구글 번역을 띄웁니다. |
| **파파고에서 번역: “…”** | 파파고 사이트를 새 탭으로 엽니다. |
| **내 PC로 번역: “…”** | 선택 옆(또는 작은 결과 창)에 내 PC 번역을 띄웁니다. 밖으로 보내지 않습니다. |
| **화면 영역 골라 번역(내 PC)** | 화면에서 영역을 끌어 골라 그림 속 글자를 읽고 번역합니다(빈 곳·그림 위에서 우클릭). |
| **이 PDF를 번역 뷰어로 열기** | PDF 링크·PDF 화면에서 번역 뷰어로 엽니다. |

### 도구 막대 아이콘(팝업)

켜기·끄기, 번역 엔진(구글·파파고·내 PC), 번역할 언어를 바로 바꿉니다. 「내 PC」를 고르면 쓰는 모델과 **「연결 시험」** 단추가 보입니다.
**「화면 영역 골라 번역(내 PC)」**, 지금 탭의 PDF를 번역 뷰어로 열기, 「PDF 파일 열기」도 여기 있습니다. 「설정 더 보기」를 누르면 전체 설정이 열립니다.

## 로컬 번역 쓰기

「내 PC」 엔진은 PC 안에서 도는 언어 모델 서버에만 요청합니다. 서버 주소는 `localhost`·`127.0.0.1`·`[::1]`만 받으므로(설정에서 다른 주소를 넣으면 거절합니다) 번역할 글과 그림이 **PC 밖으로 나가지 않습니다**.
두 가지 서버를 씁니다.

| 서버 | 방식 | 기본 주소 |
|---|---|---|
| [Ollama](https://ollama.com) (권장) | Ollama | `http://localhost:11434` |
| LM Studio, llama.cpp 서버 등 | OpenAI 호환 | `http://localhost:1234` (LM Studio) |

### 설치 순서(Ollama)

1. **Ollama 설치**: [ollama.com/download](https://ollama.com/download)에서 윈도용을 받아 설치합니다. 작업 표시줄 오른쪽에 라마 아이콘이 생기면 서버가 켜진 것입니다.
2. **확장 요청 허용(보통은 할 일 없음)**: Ollama는 처음 설치한 그대로면 출처가 `chrome-extension://…`인 요청을 **403으로 막습니다**(Ollama 0.17.0에서 확인: 같은 요청이 출처 `chrome-extension://…`이면 403, `http://127.0.0.1`이면 200).
   그래서 확장은 **자기 자신이 내 PC 서버로 보내는 요청만** 출처를 `http://127.0.0.1`로 바꿔 보냅니다(크롬 요청 규칙 `declarativeNetRequest`, 웹 페이지가 보내는 요청에는 손대지 않음). 따로 할 일이 없습니다.
   그래도 연결 시험에서 「Ollama가 확장 프로그램의 요청을 막았습니다(403)」가 뜨면 아래처럼 Ollama 쪽에서 허용합니다.
   - 윈도 「시스템 환경 변수 편집」 → 「환경 변수」 → 사용자 변수 「새로 만들기」 → 이름 **`OLLAMA_ORIGINS`**, 값 **`chrome-extension://*`**
   - 또는 명령 창에서: `setx OLLAMA_ORIGINS "chrome-extension://*"`
   - 그다음 작업 표시줄의 Ollama 아이콘 → 「Quit Ollama」로 끄고 다시 켭니다(환경 변수는 새로 켤 때 읽습니다).
3. **모델 받기**: 명령 창에서 받거나, 확장 설정 화면 「내 PC에 맞는 모델」의 **「받기」** 단추를 누릅니다.
   ```bash
   ollama pull translategemma:4b        # 번역용(3.3GB)
   ollama pull qwen3-vl:2b-instruct     # 그림 읽기용(1.9GB)
   ```
   모델은 `C:\Users\<사용자>\.ollama\models`에 저장됩니다. C 드라이브가 좁으면 환경 변수 `OLLAMA_MODELS`에 다른 폴더(예: `D:\ollama\models`)를 넣고 Ollama를 다시 켭니다.
4. **(권장) 맞춤 모델 만들기**: 번역에 맞게 조정한 모델을 만듭니다. 설정 화면의 **「맞춤 모델 만들고 쓰기」** 를 누르거나, 이 저장소 폴더에서:
   ```bash
   ollama create drag-translate -f models/drag-translate.Modelfile
   ollama create drag-translate-vision -f models/drag-translate-vision.Modelfile
   ```
5. **확장 설정에서 고르기**: 설정 화면 「번역 엔진」에서 **「내 PC」** 를 고르고, 「내 PC 번역」의 모델 이름을 확인합니다(맞춤 모델을 만들었으면 `drag-translate` / `drag-translate-vision`).
6. **연결 시험**: 「연결 시험」을 누릅니다. 서버 켜짐 → 확장 요청 허용 → 모델 있음 → 짧은 글 번역 → 그림 읽기 가능 여부를 차례로 확인하고 결과를 한국어로 알려 줍니다.

### LM Studio 쓰는 법

1. [LM Studio](https://lmstudio.ai)를 설치하고 「Discover」에서 모델을 받습니다(예: TranslateGemma, Qwen 계열 GGUF).
2. 「Developer」(개발자) 탭에서 모델을 불러오고 **「Start Server」** 를 켭니다. 설정에서 **CORS 허용(Enable CORS)** 을 켭니다.
3. 확장 설정 「서버 방식」을 **「OpenAI 호환」**, 주소를 `http://localhost:1234`로 두고 「연결 시험」을 누릅니다. 시험 결과 목록에 뜬 모델 이름을 「모델 이름」에 넣습니다.
4. LM Studio는 「받기」·「맞춤 모델 만들기」 단추를 쓰지 않습니다(Ollama 전용). 그림 읽기 가능 여부는 미리 알 수 없어 화면 영역 번역을 직접 해 봐야 합니다.

### 맞춤 모델(models 폴더)

| 맞춤 모델 | 바탕 모델 | 바꾼 점 |
|---|---|---|
| `drag-translate` | `translategemma:4b` | 온도 0.1(한결같은 번역), 문맥 2048(짧은 조각만 보내므로 작게 해 빠르게), 답 길이 1024 토큰 제한(되풀이 방지). 이 모델은 지시문을 사용자 메시지 안에서 받도록 배워 `SYSTEM`을 넣지 않습니다(확장이 요청마다 지시문을 붙입니다). |
| `drag-translate-vision` | `qwen3-vl:2b-instruct` | 온도 0, 문맥 4096(그림은 토큰을 많이 씀), 답 길이 1536 토큰, `SYSTEM`에 「그림 속 글자를 그대로 옮겨 적기만」 지시. |

두 바탕 모델 모두 생각(추론) 과정을 내지 않는 판이고, 확장은 요청마다 `think: false`(생각 끄기)와 `keep_alive: 30m`(모델을 30분 붙잡아 두어 두 번째 번역부터 바로 답하기)을 함께 보냅니다.
같은 정의가 `src/shared/models.js`에도 있어 설정 화면의 「맞춤 모델 만들고 쓰기」가 Ollama `/api/create`로 똑같이 만듭니다(시험이 두 곳이 같은지 확인합니다).

## 화면 영역 번역

스캔한 PDF, 화면 캡처, 그림 속 글자처럼 **드래그로 고를 수 없는 글자**를 번역합니다. 늘 「내 PC」 모델로만 읽고 번역하며 그림을 밖으로 보내지 않습니다.

1. 도구 막대 아이콘 → **「화면 영역 골라 번역(내 PC)」**, 또는 빈 곳·그림 위에서 우클릭 → 같은 메뉴. PDF 번역 뷰어에서는 위쪽 막대의 **「영역 번역」**.
2. 화면이 살짝 어두워지면 글자가 있는 곳을 **끌어서 사각형으로** 고릅니다. 취소는 **Esc** 또는 오른쪽 단추.
3. 「그림 속 글자를 내 PC에서 읽는 중…」 뒤에 읽은 글이 번역 창에 들어가 번역됩니다. 복사 방식·용어집도 그대로 씁니다.

동작 방식: 웹 페이지는 확장이 보이는 탭을 찍어(`chrome.tabs.captureVisibleTab`) 고른 영역만 잘라 내 PC 그림 읽기 모델에 보내고, PDF 번역 뷰어는 화면을 찍지 않고 그려 둔 쪽 그림에서 바로 잘라 더 또렷합니다.
찍은 화면은 저장하지 않습니다. 그림 읽기 모델은 설정 「그림 읽기 모델」에서 고르며, 그림을 못 읽는 모델이면 「그림을 읽을 수 있는 모델(예: 시각 모델)을 골라 주세요」라고 알려 줍니다.

| 번역 띄우는 때 | 드래그 즉시 | 「아이콘 눌러서」를 고르면 드래그 끝에 작은 「번」 단추만 뜨고, 눌러야 번역합니다. 실수로 드래그해도 번역 요청이 나가지 않습니다. |
| 최소 글자 수 | 2 | 이보다 짧게 고른 글은 번역하지 않습니다. |
| 입력칸 안의 선택은 무시 | 켜짐 | 글을 쓰는 중에 번역 창이 뜨지 않게 합니다. |
| 끊긴 줄 합치기 | 켜짐 | PDF처럼 줄 끝마다 끊긴 문장(줄 끝 하이픈, 문장 중간 줄바꿈)을 이어 붙인 뒤 번역합니다. 목록·문단·짧은 제목 줄은 남깁니다. |
| **복사 방식** | 번역문만 | 번역 창 「복사」가 넣는 모양. 아래 표 참고. 번역 창에서 바꿔도 기억합니다. |

**복사 방식**

| 방식 | 붙여 넣으면 |
|---|---|
| 번역문만 | 번역문만 들어갑니다. |
| 원문과 번역 나란히 | 문단마다 한 줄에 원문 칸·번역 칸 두 칸으로 들어갑니다. 엑셀·한글에는 표로, 메모장에는 탭으로 나뉜 글로 붙습니다. |
| 표(원문\|번역) | 「나란히」에 「원문 / 번역」 제목 줄을 더한 두 열 표입니다. 엑셀에는 칸마다(탭 구분), 한글·워드에는 표로 붙습니다(HTML 표도 함께 넣습니다). |

### 내 PC 번역

| 설정 | 기본값 | 설명 |
|---|---|---|
| 서버 방식 | Ollama | LM Studio·llama.cpp처럼 OpenAI와 같은 방식으로 답하는 서버는 「OpenAI 호환」. |
| 서버 주소 | `http://localhost:11434` | `localhost`·`127.0.0.1`·`[::1]`만 쓸 수 있습니다. 다른 주소는 거절합니다. |
| 모델 이름 | `translategemma:4b` | 번역에 쓸 모델. 맞춤 모델을 만들었으면 `drag-translate`. |
| 그림 읽기 모델 | `qwen3-vl:2b-instruct` | 화면 영역 번역에서 글자를 읽을 시각 모델. 비우면 번역 모델로 읽습니다. 맞춤 모델이면 `drag-translate-vision`. |
| 기다리는 시간(초) | 120 | 이 시간 안에 답이 없으면 멈추고 알립니다. |
| 한꺼번에 보낼 조각 수 | 1 | 긴 글을 나눈 조각을 몇 개씩 함께 보낼지(1~4). 그래픽 메모리가 넉넉하면 2~4가 빠릅니다. |
| **용어집** | 비어 있음 | 아래 참고. |
| 연결 시험 | — | 서버 켜짐, 확장 요청 허용(OLLAMA_ORIGINS), 모델 있음, 짧은 글 번역, 그림 읽기 가능 여부를 확인합니다. |
| 내 PC에 맞는 모델 | — | 사양별 추천, 「받기」(진행률 표시), 「맞춤 모델 만들고 쓰기」. |

**긴 글**은 짧은 문단을 줄바꿈째 묶고 긴 문단은 문장 단위로 잘라(조각당 700자 이하) 차례로 번역해 이어 붙입니다. 작은 모델은 짧게 여러 번 묻는 편이 빠르고 정확합니다.

**용어집**: 한 줄에 하나씩 `원어 = 번역어`로 적습니다. `#`으로 시작하는 줄은 메모입니다.

```
# 계측제어 용어
계측제어 = I&C
형상관리 = configuration management
압력 전송기 = pressure transmitter
```

- 번역할 글에 나오는 용어만 번역 지시문에 넣습니다(지시문이 짧을수록 작은 모델이 잘 따릅니다).
- 반대 방향으로 번역할 때(영어 → 한국어에서 `I&C`가 나오면)는 뒤집어 `I&C = 계측제어`로 넣습니다.
- 모델이 번역어를 띄어쓰기만 달리 쓰면(「원자로 보호 계통」) 용어집대로(「원자로보호계통」) 바로잡습니다.
- 내 PC 번역에만 쓰고 구글·파파고에는 넣지 않습니다. 용어집은 길어질 수 있어 계정 동기화 저장소가 아니라 **이 PC에만** 저장합니다.

## 동작 원리와 개인정보

- **내 PC(로컬) 엔진은 외부로 아무것도 보내지 않습니다.** 번역할 글, 화면 영역 번역의 그림, 용어집은 내 PC의 서버(`localhost`·`127.0.0.1`·`[::1]`)로만 갑니다. 다른 주소는 설정에서 거절하고, 요청을 보내기 전에 한 번 더 확인합니다. 내 PC 번역 창에는 글을 구글로 넘기는 링크도 두지 않습니다.
- **구글** 엔진은 드래그한 글을 **번역할 때만** 구글 번역 서버(`translate.googleapis.com`)로 보냅니다. 페이지 전체나 방문 기록은 보내지 않습니다.
- 파파고는 `papago.naver.com`을 새 탭으로 여는 것뿐이고, 확장이 파파고 서버로 직접 요청하지 않습니다.
- 번역 결과는 저장하지 않습니다. 브라우저가 켜져 있는 동안 같은 글을 다시 고르면 메모리에 둔 결과를 다시 씁니다. 찍은 화면도 저장하지 않습니다.
- 「받기」를 누르면 Ollama가 모델을 Ollama 공식 저장소에서 내려받습니다(사용자가 눌렀을 때만). 번역할 글은 이때도 나가지 않습니다.
- 외부 분석·광고 코드가 없습니다. PDF.js는 확장 안에 들어 있어 따로 내려받지 않습니다.

| 권한 | 왜 필요한가 |
|---|---|
| `storage` | 설정·용어집 저장 |
| `contextMenus` | 우클릭 메뉴(「구글로 번역」, 「파파고에서 번역」, 「내 PC로 번역」, 「화면 영역 골라 번역」, 「이 PDF를 번역 뷰어로 열기」) |
| `declarativeNetRequest` | `.pdf` 주소를 번역 뷰어로 돌리기(「PDF를 번역 뷰어로 열기」 설정이 켜져 있을 때만). 그리고 이 확장이 내 PC 서버(`localhost`·`127.0.0.1`·`[::1]`)로 보내는 요청의 출처를 `http://127.0.0.1`로 바꿔 Ollama의 403을 피하기(이 확장이 보낸 요청만, 웹 페이지 요청은 그대로) |
| 모든 사이트 접근(`<all_urls>`) | 어느 페이지에서든 드래그를 감지하고, 번역 뷰어가 다른 사이트의 PDF를 불러오기 위해. 같은 권한으로 내 PC 번역 서버(`http://localhost`)에 요청하고, 화면 영역 번역에서 보이는 탭을 찍습니다(`captureVisibleTab`) — 그래서 `activeTab` 같은 권한을 더 받지 않았습니다. |

> **회사 문서 주의**: 보안 문서는 **로컬(내 PC) 엔진을 쓰세요**. 구글 엔진은 드래그한 글을 외부 번역 서버로 보냅니다. 팝업에서 엔진을 「내 PC」로 두거나, 우클릭 「내 PC로 번역」을 쓰면 글이 PC 밖으로 나가지 않습니다. 확장을 아예 꺼 두려면 팝업의 스위치를 끕니다.

## 알아 둘 점

- **구글 번역**은 구글 번역 사이트가 쓰는 공개 통로를 키 없이 씁니다. 짧은 시간에 아주 많이 요청하면 잠시 막힐 수 있고, 그때는 「요청이 너무 잦아…」 안내가 뜹니다. 잠시 뒤 다시 하거나 「구글 번역에서 열기」를 쓰세요.
- 한 번에 **30,000자**까지 번역합니다. 긴 글은 조각(구글 4,500자·내 PC 700자)으로 나눠 차례로 보내고 「n/전체 조각 (몇 %)」로 진행을 보입니다. 30,000자를 넘으면 앞부분만 번역하고 남은 글자 수를 알립니다(문단·문장 끝에서 자릅니다). 파파고·구글 번역 **사이트**로 여는 경우는 사이트가 받는 앞 5,000자만 싣습니다.
- 복사 방식 「원문과 번역 나란히」「표」는 HTML 표와 탭으로 나눈 글을 함께 넣어, 엑셀·한글에 붙이면 두 칸짜리 표가 됩니다(「표」는 「원문 | 번역」 제목 줄이 더 붙습니다). 메모장에는 탭으로 나뉜 글로 붙습니다.
- **내 PC 번역**은 PC 사양과 모델에 따라 속도가 크게 다릅니다. 처음 한 번은 모델을 불러오느라 몇 초 더 걸리고, 30분 동안 쓰지 않으면 모델이 내려가 다시 몇 초 걸립니다.
- 작은 모델은 원문 언어를 글자 모양으로 어림합니다. 라틴 문자 글(프랑스어·독일어 등)은 영어로 어림하지만 대개 제대로 번역합니다.
- **크롬 기본 PDF 뷰어** 안에서는 크롬이 확장에게 선택한 글을 보여 주지 않습니다. 그래서 PDF는 번역 뷰어로 열거나, 기본 뷰어에서는 우클릭 번역을 씁니다. 화면 영역 번역도 기본 뷰어에서는 되지 않으니 번역 뷰어의 「영역 번역」을 쓰세요.
- `chrome://` 화면, 크롬 웹 스토어, 다른 확장의 화면에서는 크롬 정책상 동작하지 않습니다. 이런 화면에서 「화면 영역 골라 번역」을 고르면 까닭과 할 일을 작은 창으로 알립니다.
- 주소가 `.pdf`로 끝나지 않는 PDF(`download?id=123`처럼 서버가 `Content-Type: application/pdf`로 보내는 것)도 번역 뷰어로 엽니다. 크롬 128 이상은 요청 규칙이 응답 머리를 보고 옮기고, 그보다 오래된 크롬은 PDF가 열린 뒤 확장이 알아채고 옮깁니다. 다만 다음은 원래대로 둡니다: 「내려받기」로 오는 응답(`Content-Disposition: attachment` — 크롬이 파일로 저장), 양식 제출(POST)로 만든 PDF, 다른 화면 속 틀(iframe)에 든 PDF, 내 컴퓨터 파일(`file://`), 「원래 뷰어로 보기」를 고른 주소.

## 문제 해결

| 증상 | 해결 |
|---|---|
| 드래그해도 아무것도 안 뜬다 | ① 팝업에서 스위치가 켜져 있는지 봅니다. ② 설치·업데이트 전부터 열려 있던 탭이면 **새로 고칩니다**. ③ 입력칸 안이라면 설정 「입력칸 안의 선택은 무시」를 끕니다. |
| 「확장 프로그램이 다시 로드되었습니다」가 뜬다 | 확장을 새로 고치기 전부터 열려 있던 탭입니다. 탭을 새로 고치세요. |
| 「내 PC 번역 서버가 꺼져 있습니다」 | 작업 표시줄에 Ollama 아이콘이 있는지 봅니다. 없으면 시작 메뉴에서 Ollama를 켭니다. LM Studio는 「Start Server」를 켭니다. 서버 주소·방식이 맞는지도 봅니다. |
| 「Ollama가 확장 프로그램의 요청을 막았습니다(403)」 | 확장이 출처를 바꿔 보내는데도 막힌 경우입니다. 명령 창에서 `setx OLLAMA_ORIGINS "chrome-extension://*"` 를 실행하고 Ollama를 **끝냈다가 다시** 켭니다([설치 순서 2번](#설치-순서ollama)). |
| 「배경 작업이 답을 주기 전에 멈췄습니다」 | 크롬이 확장의 배경 작업(서비스 워커)을 끝낸 경우입니다. 확장은 번역하는 동안 20초마다 깨워 두지만, 그래도 나면 한 번 더 시도하고, 되풀이되면 더 작은 모델을 고르거나 크롬을 다시 켭니다. `chrome://extensions` → 「드래그 번역」 → 「서비스 워커」 링크에서 기록을 볼 수 있습니다. |
| 「모델 …이(가) 내 PC에 없습니다」 | 설정 「내 PC에 맞는 모델」의 「받기」를 누르거나 `ollama pull 모델이름`. 맞춤 모델(`drag-translate`)이면 「맞춤 모델 만들고 쓰기」나 `ollama create`. |
| 「…초 안에 답하지 않았습니다」 | 더 작은 모델을 고르거나 「기다리는 시간」을 늘립니다. 첫 번역은 모델을 불러오느라 오래 걸릴 수 있습니다. |
| 「그림을 읽을 수 있는 모델(예: 시각 모델)을 골라 주세요」 | 「그림 읽기 모델」을 `qwen3-vl:2b-instruct`(또는 `drag-translate-vision`)로 두고 그 모델을 받습니다. |
| 「그림에서 글자를 찾지 못했습니다」 | 글자가 있는 곳을 조금 더 넉넉하게 고릅니다. 글자가 너무 작으면 화면을 확대한 뒤 고릅니다. |
| 「이 화면에서는 영역 번역을 쓸 수 없습니다」 | 크롬 내부 화면·웹 스토어·크롬 기본 PDF 뷰어입니다. PDF는 번역 뷰어로 연 뒤 「영역 번역」을 씁니다. |
| 내 PC 번역 결과에 한자가 섞인다 | 확장이 한 번 다시 묻지만, 계속되면 `translategemma:4b`처럼 번역 전용 모델로 바꿉니다(`qwen2.5:7b`에서 실측된 문제). |
| 「받기」가 중간에 끊긴다 | 설정 화면을 닫으면 받기도 멈춥니다. 큰 모델은 명령 창에서 `ollama pull 모델이름`으로 받는 편이 안전합니다. |
| PDF가 번역 뷰어로 안 열린다 | 설정 「PDF를 번역 뷰어로 열기」가 켜져 있는지, 주소가 `.pdf`로 끝나는지 봅니다. 아니면 팝업의 「이 PDF를 번역 뷰어로 열기」를 누릅니다. |
| 번역 뷰어에 「PDF를 불러오지 못했습니다」가 뜬다 | 로그인이 필요한 사이트의 PDF일 수 있습니다. 「원래 뷰어로 보기」를 누른 뒤 우클릭 번역을 쓰세요. 내 컴퓨터 파일이면 [3단계](#3-선택-내-컴퓨터의-pdf도-쓰려면) 권한을 켜거나 「파일 직접 열기」를 누릅니다. |
| 한글·한자가 깨진 PDF | 번역 뷰어에는 PDF.js의 글꼴 지도(cMaps)가 들어 있습니다. 그래도 깨지면 PDF 자체에 글자 정보가 없는 경우입니다. 「영역 번역」으로 그림처럼 읽어 보세요. |
| 번역 창이 페이지 모양과 섞인다 | 번역 창은 페이지와 분리된 그림자 DOM에 그려집니다. 재현되는 주소를 이슈로 알려 주세요. |

## 개발

빌드 과정이 없는 순수 자바스크립트 확장입니다. 받은 폴더를 그대로 크롬에 올리면 됩니다.

```
manifest.json              확장 정의(매니페스트 3판)
src/background.js          서비스 워커: 구글·내 PC 번역 요청, 결과 기억, 우클릭 메뉴, 화면 찍기·자르기, 모델 받기·만들기, PDF 자동 열기 규칙
src/shared/config.js       설정 기본값·검증·저장(내 PC 주소 검증 포함)
```

```bash
npm test               # 시험(노드 20 이상, 따로 설치할 것 없음)
npm run pack           # dist/drag-translate-<버전>.zip 만들기(노드 내장 기능만 씀)
npm run bench:local    # 내 PC 번역 실측: npm run bench:local -- drag-translate drag-translate-vision
npm install            # PDF.js를 새 버전으로 바꿀 때만
npm run vendor         # node_modules/pdfjs-dist → vendor/pdfjs 복사
npm run icons          # 아이콘 다시 그리기
```

`npm run pack`은 `manifest.json`·`README.md`·`icons`·`src`·`vendor`·`models`만 묶고 시험·개발 도구·`node_modules`·`.cache`는 뺍니다. 파일 이름에 매니페스트 판(예: `1.1.1`)이 들어갑니다.

코드를 고친 뒤에는 `chrome://extensions`에서 새로고침(⟳)을 누르고, 시험할 탭도 새로 고칩니다.
서비스 워커 기록은 확장 카드의 「서비스 워커」 링크에서, 번역 창과 뷰어 기록은 그 탭의 개발자 도구(F12)에서 봅니다.
