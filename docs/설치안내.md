# 드래그 번역 설치 안내

웹 페이지와 PDF에서 글자를 드래그하면 그 자리에서 번역해 주는 크롬 확장 프로그램입니다.
보안 문서는 「내 PC」 엔진을 쓰시면 글이 PC 밖으로 나가지 않습니다. 처음 설치하시는 분 기준으로 10분 정도 걸립니다.

## ① 설치본 풀기와 크롬에 올리기

1. 받으신 `drag-translate-<판 번호>.zip` 파일을 오른쪽 단추로 누르고 **「압축 풀기」** 를 고릅니다.
   지워지지 않을 곳(예: `D:\tools\drag-translate`)에 풀어 주세요. **설치한 뒤 이 폴더를 지우거나 옮기면 확장이 사라집니다.**
2. 푼 폴더를 열었을 때 `manifest.json` 파일이 바로 보이는지 확인합니다(한 단계 안쪽 폴더에 있으면 그 폴더를 씁니다).
3. 크롬 주소창에 `chrome://extensions` 를 입력하고 Enter를 누릅니다.
4. 화면 오른쪽 위 **「개발자 모드」** 스위치를 켭니다.
5. 왼쪽 위에 생긴 **「압축해제된 확장 프로그램을 로드합니다」** 단추를 누릅니다.
6. 2번에서 확인한 폴더를 고르고 **「폴더 선택」** 을 누릅니다.
7. 목록에 「드래그 번역 (Drag Translate)」이 나타나고 설정 화면이 한 번 열리면 설치가 끝난 것입니다.
8. 주소창 오른쪽 퍼즐 모양 아이콘 → 「드래그 번역」 옆 핀 단추를 누르면 도구 막대에 아이콘이 고정됩니다.

> 크롬을 켤 때 「개발자 모드 확장 프로그램 사용 중지」 알림이 뜨면 **「취소」** 를 눌러 그대로 쓰시면 됩니다.
> 설치 전부터 열려 있던 탭은 새로 고쳐야 드래그 번역이 붙습니다.

## ② 내 PC 번역 준비(Ollama와 모델)

구글 엔진만 쓰실 거면 이 단계는 건너뛰셔도 됩니다. 회사 문서를 번역하실 때는 꼭 준비해 주세요.

1. [ollama.com/download](https://ollama.com/download)에서 Windows용 설치 파일을 받아 설치합니다.
   설치가 끝나 작업 표시줄 오른쪽에 라마 모양 아이콘이 보이면 번역 서버가 켜진 것입니다.
2. 확장 아이콘 → **「설정 더 보기」** 를 눌러 설정 화면을 엽니다.
3. 「번역 엔진」에서 **「내 PC」** 를 고릅니다.
4. 「내 PC에 맞는 모델」에 나오는 **설정 화면의 추천 모델** 옆 **「받기」** 를 누릅니다. 수 GB라 몇 분 걸리며, 받는 동안 설정 화면을 닫지 마세요.
   받기가 끝나면 그 모델을 「모델 이름」에 둡니다.

## ③ 연결 시험

설정 화면(또는 확장 아이콘을 눌러 나오는 작은 창)의 **「연결 시험」** 을 누릅니다.
「연결됐습니다. 시험 번역: …」이 나오면 준비가 끝난 것입니다. 처음 한 번은 모델을 불러오느라 수십 초 걸릴 수 있습니다.

## ④ 첫 번역

1. 영어로 된 웹 페이지를 **새로** 엽니다.
2. 한 문장을 마우스로 드래그합니다. 선택한 글 바로 아래에 번역 창이 뜹니다.
3. 번역 창 위쪽에서 엔진(구글 · 파파고 · 내 PC)과 번역할 언어를 바꿀 수 있습니다. 「복사」로 번역문을 가져갑니다.
4. PDF 링크를 열면 확장에 들어 있는 **PDF 번역 뷰어**로 열리고, 쪽 안의 글자를 똑같이 드래그해 번역합니다.
   내 컴퓨터에 있는 PDF는 확장 아이콘 → 「PDF 파일 열기」로 고릅니다.

## ⑤ 막혔을 때

| 이런 말이 나오면 | 이렇게 해 주세요 |
|---|---|
| 「Ollama가 확장 프로그램의 요청을 막았습니다(403)」 | 시작 메뉴에서 「명령 프롬프트」를 열고 `setx OLLAMA_ORIGINS "chrome-extension://*"` 를 입력해 Enter를 누릅니다. 작업 표시줄의 라마 아이콘을 오른쪽 단추로 눌러 「Quit Ollama」로 끈 뒤, 시작 메뉴에서 Ollama를 다시 켜고 연결 시험을 다시 누릅니다. |
| 「모델 …이(가) 내 PC에 없습니다」 | 설정 화면 「내 PC에 맞는 모델」에서 추천 모델의 「받기」를 누르거나, 연결 시험 결과 끝에 나오는 「받아 둔 모델」 가운데 하나를 「모델 이름」에 넣습니다. |
| 「내 PC 번역 서버가 꺼져 있습니다」 | 작업 표시줄에 라마 아이콘이 없으면 시작 메뉴에서 Ollama를 켭니다. |
| 번역이 느리다, 「…초 안에 답하지 않았습니다」 | 첫 번역은 모델을 불러오느라 느립니다. 한 번 더 해 보시고, 계속 느리면 설정 화면의 추천 모델 가운데 더 작은 것을 받아 바꾸거나 「기다리는 시간」을 늘립니다. 긴 글은 조각마다 진행률이 표시됩니다. |
| 드래그해도 아무것도 안 뜬다 | 확장 아이콘의 스위치가 켜져 있는지 보시고, 탭을 새로 고칩니다. |

그래도 안 되면 화면에 나온 문구를 그대로 적어 담당자에게 알려 주세요.

## 개발자 모드 없이 회사에서 일괄 설치하려면

> **이 절은 IT 담당 부서가 결정할 사항입니다.** 아래는 방식의 개요와 검토에 필요한 준비물이며, 실제 적용 여부·서버·배포 범위는 IT팀이 정합니다.

크롬은 회사 정책으로 확장을 강제 설치할 수 있습니다. 웹 스토어에 올리지 않고 사내 서버에서 배포하는 방식은 다음과 같습니다.

1. **설치 파일(CRX) 만들기**: `chrome://extensions` → 「확장 프로그램 압축」으로 설치본 폴더를 묶으면 `.crx` 파일과 서명 키(`.pem`)가 생깁니다.
   확장 ID는 이 키로 정해지므로 **키를 잃어버리면 같은 확장으로 갱신할 수 없습니다.** 키는 IT팀이 안전하게 보관합니다.
2. **사내 서버에 두기**: CRX 파일과 갱신 정보 파일(update XML, 확장 ID·판 번호·CRX 주소를 적은 것)을 사내 웹 서버(가능하면 HTTPS)에 올립니다.
3. **정책 걸기**: 그룹 정책(GPO)의 크롬 관리 템플릿에서 `ExtensionInstallForcelist` 에 `확장ID;https://사내서버/drag-translate/updates.xml` 을 넣습니다(같은 일을 `ExtensionSettings` 의 `force_installed` 로도 할 수 있습니다). 엣지도 같은 이름의 정책이 있습니다.
4. **갱신**: 새 판을 낼 때 같은 키로 CRX를 다시 만들고 update XML의 판 번호를 올립니다. 크롬이 주기적으로 확인해 자동으로 바꿉니다.

알아 두실 제약:

- Windows에서 크롬은 **도메인(Active Directory)에 가입된 PC이거나 크롬 클라우드 관리(Chrome Browser Cloud Management)에 등록된 브라우저에서만** 웹 스토어 밖의 확장을 강제 설치합니다. 그 밖의 PC에서는 정책을 걸어도 설치되지 않습니다.
- 크롬 정책 설명에 따르면 정책에 적은 갱신 주소는 첫 설치에만 쓰이고, 그 뒤 갱신은 확장 `manifest.json` 의 `update_url` 을 따릅니다. 자동 갱신까지 하려면 배포용 판에 `update_url` 을 넣어야 합니다(지금 설치본에는 넣지 않았습니다 — 서버 주소가 정해지면 개발 쪽에서 넣습니다).
- 「내 PC」 번역은 PC마다 Ollama와 모델이 있어야 합니다. 확장 일괄 설치와 별개로 Ollama 배포(설치 파일·모델 파일 저장 위치)도 함께 정해야 합니다.

IT 담당자께 전달할 준비물:

| 준비물 | 내용 |
|---|---|
| 설치본 zip | `npm run pack` 으로 만든 `drag-translate-<판 번호>.zip`(이 안내서 포함) |
| 확장 ID와 서명 키 | 처음 CRX를 만들 때 생기는 `.pem`(IT팀 보관). ID는 `chrome://extensions` 에서 확인 |
| 사내 배포 서버 주소 | CRX와 update XML을 둘 곳(HTTPS 권장). 정해지면 `manifest.json` 의 `update_url` 에 반영 |
| 정책 적용 범위 | 대상 부서·PC(도메인 가입 또는 클라우드 관리 등록 여부), 크롬·엣지 중 어느 쪽인지 |
| 필요한 권한 설명 | 모든 사이트 접근(드래그 감지·PDF 뷰어·내 PC 서버 요청), 저장소, 우클릭 메뉴, 요청 규칙. 자세한 까닭은 README 「동작 원리와 개인정보」 |
| 외부 통신 | 구글 엔진을 쓸 때만 `translate.googleapis.com` 으로 글이 나갑니다. 보안상 막으려면 「내 PC」 엔진만 쓰도록 안내하거나 해당 주소를 차단합니다 |
| Ollama 배포 방식 | Ollama 설치 파일, 모델을 받아 둘 위치(`OLLAMA_MODELS`), 403이 날 때의 `OLLAMA_ORIGINS` 설정 |
