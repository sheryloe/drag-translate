드래그 번역 설정

웹 페이지와 PDF에서 글자를 드래그하면 그 자리에서 번역합니다.

설치가 끝났습니다

  1. 아무 웹 페이지에서 글자를 드래그해 보세요. 선택 옆에 번역 창이 뜹니다.
  2. PDF 주소를 열면 번역 뷰어로 열립니다. 쪽 안의 글자를 드래그하면 같은 방법으로 번역합니다.
  3. 내 컴퓨터의 PDF도 쓰려면 아래 「내 컴퓨터의 PDF」 안내를 따라 권한을 켜 주세요.

번역

드래그 번역 켜기
번역 엔진구글은 선택 옆에 바로 보이고, 파파고는 번역 창의 단추로 파파고 사이트를 새 탭에 엽니다. 「내 PC」는 아래 「내 PC 번역」에 적은 PC 안의 언어 모델로 번역하고 밖으로 아무것도 보내지 않습니다.
번역 띄우는 때「아이콘」을 고르면 드래그 끝에 작은 「번」 단추가 뜨고, 눌러야 번역합니다.
입력칸 안의 선택은 무시글을 쓰는 중에 번역 창이 뜨지 않게 합니다.
끊긴 줄 합치기PDF처럼 줄 끝마다 끊긴 문장(줄 끝 하이픈, 문장 중간 줄바꿈)을 이어 붙인 뒤 번역합니다. 목록과 문단 나눔은 남깁니다.

내 PC 번역(로컬)

보안 문서는 이 엔진을 쓰세요. PC 안에서 도는 언어 모델 서버(Ollama, LM Studio 등)에만 보내고 밖으로는 아무것도 보내지 않습니다. 설치 방법은 README의 「로컬 번역 쓰기」에 있습니다.

서버 방식LM Studio·llama.cpp 서버처럼 OpenAI와 같은 방식으로 답하는 서버는 「OpenAI 호환」을 고릅니다.
연결 시험서버가 켜져 있는지, 확장 요청을 막지 않는지(OLLAMA_ORIGINS), 모델이 있는지, 짧은 글을 실제로 번역하는지, 그림 읽기 모델이 그림을 읽을 수 있는지 차례로 확인합니다.

내 PC에 맞는 모델

번역은 작고 빠른 모델이 먼저입니다. PC 사양을 고르면 번역용·그림 읽기용 모델을 추천합니다. 「받기」는 누를 때만 Ollama가 모델을 내려받습니다(Ollama 전용).

맞춤 모델추천 모델을 바탕으로 번역에 맞게 조정한 모델(drag-translate, drag-translate-vision)을 만듭니다. 온도를 낮추고 문맥·답 길이를 줄여 더 빠르고 한결같이 번역합니다. 바탕 모델을 먼저 받아 두어야 합니다.

PDF

PDF를 번역 뷰어로 열기주소가 .pdf로 끝나는 문서를 열면 크롬 기본 뷰어 대신 번역 뷰어로 엽니다. 끄면 크롬 기본 뷰어에서 글자를 고른 뒤 우클릭 「구글로 번역」을 쓰세요.
